# JOSPAT — Основа

Откройте index.html в браузере. Сборка и установка зависимостей не требуются.

На главной шесть разделов: «Основа», «Аналитика», «Заметки», «Цели», «Дневник» и «Карта мыслей». В «Основе» есть трекер привычек, серия побед и календарь. Привычку можно быстро добавить под таблицей или одним нажатием из девяти шаблонов; для выбора дней недели есть кнопка «Настроить дни». График показывает процент выполненных привычек по дням, а серия побед засчитывает дни с результатом от 70%. В календарь можно добавить важное событие с датой и временем. Аналитика показывает общий результат, лучший день и выполнение каждой привычки. В заметках можно писать, искать и закреплять записи.

В дневнике можно записывать сон, энергию, настроение, урок дня, благодарность и мысли. Каждая дата хранит отдельную запись; сбоку показаны смайлики за последние семь дней. В «Целях» можно записать причину, срок и шаги; прогресс считается по выполненным шагам. Карта мыслей показывает цветные соединённые ветки на прокручиваемом полотне. При выбранной ветке Space создаёт соседнюю ветку, Tab вкладывает её в предыдущую, Shift+Tab извлекает на уровень выше, Enter создаёт дочернюю, F2 открывает редактирование, Delete удаляет ветку. На телефоне действия доступны в нижней панели. Эти сочетания не перехватываются в текстовых полях.

Данные сохраняются в текущем браузере. При первом открытии показаны примерные привычки и задачи.

Остальные ветки платформы обозначены в боковом меню для ориентира.
