# JOSPAT — Основа

Откройте index.html в браузере. Сборка и установка зависимостей не требуются.

На главной расположены карточки разделов. В «Основе» есть трекер привычек и календарь. Привычку можно быстро добавить под таблицей или одним нажатием из девяти шаблонов; для выбора дней недели есть кнопка «Настроить дни». В трекере показаны отметки, проценты, звёзды и график изменения выполнения по дням. В календарь можно добавить важное событие с датой и временем. Изменения сохраняются в текущем браузере. При первом открытии показаны примерные привычки и задачи.

Остальные ветки платформы обозначены в боковом меню для ориентира.
