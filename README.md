# JOSPAT — Основа

Откройте index.html в браузере. Сборка и установка зависимостей не требуются.

На главной четыре раздела: «Основа», «Аналитика», «Заметки» и «Цели» (раздел целей пока в планах). В «Основе» есть трекер привычек, серия побед и календарь. Привычку можно быстро добавить под таблицей или одним нажатием из девяти шаблонов; для выбора дней недели есть кнопка «Настроить дни». График показывает процент выполненных привычек по дням, а серия побед засчитывает дни с результатом от 70%. В календарь можно добавить важное событие с датой и временем. Аналитика показывает общий результат, лучший день и выполнение каждой привычки. В заметках можно писать, искать и закреплять записи. Данные сохраняются в текущем браузере. При первом открытии показаны примерные привычки и задачи.

Остальные ветки платформы обозначены в боковом меню для ориентира.
