# JOSPAT Core

Откройте index.html в браузере. Сборка и установка зависимостей не требуются.

В трекере можно добавить привычку вручную или из девяти шаблонов, выбрать дни недели и отмечать выполнение. План недели и календарь показывают одни и те же задачи. Изменения сохраняются в текущем браузере. При первом открытии показана примерная неделя.

Остальные ветки платформы обозначены в боковом меню для ориентира.
